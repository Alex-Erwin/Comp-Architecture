# Project Status

## Update: September 30, 2026

We are currently planning our two-board multiplayer game. We are considering Pong, but have not made a final decision on the game yet. There is no working game or tested connection between the boards yet.

## What We Accomplished This Week

- Wrote our initial project idea.
- Received feedback that the game needs to use two boards for multiplayer.
- Updated the plan so each player will use a separate Milk-V Duo S board.
- Prepared the README and this status update to explain the project and our progress.

## What Still Needs to Be Decided

- The final game we will build.
- Whether the small LCD screens we purchased will work for the game.
- What controls each player will use.
- How the two boards will communicate.

## Possible Wi-Fi Connection

We are considering connecting both boards to the same Wi-Fi network. One board would handle the main game and score, while the other would send its player's button inputs. The first board would send game updates back so both screens show the same game. We still need to check whether our boards have Wi-Fi and test the connection. If Wi-Fi does not work or our boards do not support it, we could use a wired LAN connection by connecting both boards to the same router with Ethernet cables.

## Next Steps

- Test the LCD screens with the boards.
- Choose the game and controls.
- Check whether our boards have Wi-Fi and test sending simple information between them.
- Begin a basic version of the game once the setup is decided.
