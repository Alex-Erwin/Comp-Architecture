# Two-Board Multiplayer Game

## Project Idea

Our project is to make a two-player game using two Milk-V Duo S boards. Each player will use their own board with a screen and controls. The boards will communicate so both players can play the same game against each other.

We are currently considering a simple game like Pong. The exact game may change as we work on the project, but using two boards for multiplayer will be part of the final design.

## Planned Features

- Two players using separate Milk-V Duo S boards.
- A screen and controls for each player.
- Communication between the boards to keep the game updated for both players.
- Basic gameplay and score tracking.

## Hardware

We plan to use two Milk-V Duo S boards. We have purchased small LCD screens, but still need to test whether they will work for the game. We also need to decide what controls to use and how the boards will connect.
